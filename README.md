# SIGRI - Frontend local

Prototipo funcional sin backend, con datos precargados y persistencia únicamente en memoria.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir `http://localhost:5173`.

## Alcance

- React + TypeScript + Vite.
- Leaflet y OpenStreetMap para el mapa georreferenciado.
- Sin API ni base de datos.
- CRUD simulado, filtros, historial, roles, modales, notificaciones y atajos de teclado.
